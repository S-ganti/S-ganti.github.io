How this demo works

The chat runs a real state machine (bot-core.js): greeting, menu, size, quantity, date and slot with a same-day cutoff, cake message, pickup or delivery with HSR, Koramangala and BTM fees, summary, a UPI advance link and an order ID. The same file is covered by automated tests and is embedded in an n8n workflow for the WhatsApp Cloud API. That workflow has not been tested against a live WhatsApp Business account yet.
