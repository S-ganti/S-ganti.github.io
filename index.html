Lehar: see where a market move reaches your money

Problem
A retail investor holding mutual funds can't see which companies they really own, or how a move in crude oil or the rupee reaches them.
What I built
One static page that opens funds into their holdings, adds direct stocks, and maps each company to the factors that move its costs or revenue. Pick a factor and watch its reach spread across your companies like the monsoon advancing. Built on the Nifty 500 and fund houses' own monthly disclosures.
Result
A working prototype on GitHub Pages, still being improved. It shows overlap ("you own HDFC Bank 3 ways") and how much of your money is actually measured. Information only: no buy, sell or hold views.

A WhatsApp ordering bot for a home bakery

Problem
Home bakers take orders on WhatsApp in between baking. When a reply takes an hour, the customer has often ordered somewhere else, and the details (size, date, message on the cake, address) get lost in a long chat.
What the bot does
It takes a cake order from start to finish: menu with prices, size and quantity, a date and time slot (it refuses past dates, and same-day orders after 11 am), the message on the cake, pickup or delivery with fees for HSR, Koramangala and BTM, a summary with the total, a UPI link for a 50% advance, and an order ID. Customers can type freely, or reply back, cancel or talk to human at any point. Each order shows up in an owner view.
How it is built
The ordering logic is one plain JavaScript file with automated tests. The same file runs in the web demo and inside an n8n workflow wired to the WhatsApp Cloud API. That workflow has not been tested on a live WhatsApp Business number yet.

Butterbird Home Bakery is fictional, and so is the UPI ID. There are no real orders or results.

Try the demo → n8n workflow (JSON)
  1. Hi, then the menu5 cakes, ½ / 1 / 2 kg prices
  2. Cake, size, quantity"red velvet 1kg" works in one message
  3. Date and slotNo past dates; same-day closes at 11 am
  4. Message on the cakeUp to 30 characters, or none
  5. Pickup or deliveryHSR ₹40, Koramangala ₹70, BTM ₹90
  6. Summary and totalReply yes, back or cancel
  7. UPI advance link, order IDupi://pay link with a demo UPI ID

Each step is a state in the bot. Back, cancel and talk to human work from any of them.

How a project runs

  1. Scope the question

    A short call, then a one-page note: what you need, what's in, what's out, the price and the date.

  2. Source the data

    Your own exports, official statistics or public filings. Each source is listed with its date before any building starts.

  3. Build and test

    Models get checked against each other; automations run on real samples first. Where the data can't support a number, I say so.

  4. Hand over

    Files you own, a plain-language summary, and a walkthrough so your team can run it without me.
